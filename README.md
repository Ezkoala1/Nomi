## ✨ About

**Nomi** is a modern social platform focused on keeping communication simple.

Chat with people, discover users, share posts and follow the people you care about — all in one place.

Built with a clean interface and designed to feel fast, simple and familiar.

---

## 🌟 Features

| 💬 Messaging              | 📰 Social                   |
| ------------------------- | --------------------------- |
| Real-time conversations   | Create posts                |
| Private chats             | Share text, images & videos |
| Conversation search       | Follow people               |
| Custom conversation names | Personalised feed           |

| 👤 Profiles       | 🔎 Discovery        |
| ----------------- | ------------------- |
| Custom usernames  | Search users        |
| Display names     | Discover people     |
| Profile pictures  | Follow accounts     |
| Verified profiles | Start conversations |
